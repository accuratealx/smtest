# Decisions (ADRs)

One file per decision that is not obvious from the code:
`NNNN-short-title.md`, numbered in order, never renumbered or rewritten — a
later ADR supersedes an earlier one and says so. Keep each under a page:

```markdown
# NNNN — Title

- Status: accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
What forces the decision.
## Options
1. ... 2. ...
## Decision
What we chose and why.
## Consequences
What gets easier, what gets harder, what to watch.
```
